# Frontend de BuyerBrain

Este directorio alojará la web app responsive de BuyerBrain. Todavía no existe código de frontend.

Antes de comenzar:

1. leer `AGENTS.md`;
2. revisar el contexto y el MVP;
3. crear y validar el design system en `Frontend/Design_system`;
4. construir primero el recorrido principal de la web app.

No se desarrollará una aplicación móvil nativa.
